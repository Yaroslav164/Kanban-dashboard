# Локальный векторный индекс кода

Индекс помогает найти исходники по имени класса, компонента, маршрута или сочетанию терминов. Результаты содержат путь и диапазон строк. Перед изменением кода откройте найденный файл и проверьте контекст.

Из корня репозитория с Git и Python 3.11 или новее:

```sh
python scripts/code-index.py build
python scripts/code-index.py query "CardTemplateService checklist" --limit 5
python scripts/code-index.py query "Reverb board channel" --show-code
```

Команда `build` пересобирает базу `.code-index/code.sqlite3` из текущей рабочей копии. Запускайте её после изменений и переключения ветки. Чтобы новый исходник попал в индекс, добавьте его в Git. Список индексируемых каталогов и файлов задан в [скрипте](../scripts/code-index.py). Старые приложения `backend/` и `frontend/`, локальные файлы окружения, зависимости и результаты сборки исключены.

Скрипт хранит фрагменты кода и числовые векторы в SQLite и ранжирует их по косинусному сходству. Векторы формируются из слов и частей идентификаторов. Для поиска подходят названия из кода и предметные термины. Поиск по смысловым перефразировкам и перевод запросов не поддерживаются.

Индексирование и поиск выполняются локально без сетевых запросов или API-ключей. SQLite-файл исключён из Git и Docker-контекста. Каждый разработчик может пересобрать его в своей рабочей копии.

Проверки индексатора запускаются из корня репозитория командой `python -m unittest discover -s scripts -p test_code_index.py`.
