# Тикеты Kanban MVP

Статус — выбраны email/password, GitHub OAuth и Reverb. Схема БД и OpenAPI согласованы. Проект использует Laravel 13.43.0.

Реализованы тикеты 01–10, включая GitHub OAuth и Reverb. Локальная приёмка подтвердила Pest на PostgreSQL 16 с покрытием 95,8%, Vitest, Playwright, Pint, ESLint, Prettier и совпадение Swagger YAML с контрактом. Для проверки через настоящий GitHub требуются реквизиты OAuth App. Отдельный тест двух конкурирующих транзакций из тикета 07 остаётся открытым.

| ☐ 03. Вход | backend · auth, роуты и Pest | 01–02 | Регистрация, вход, просмотр сессии и выход по контракту. Проверяются CSRF, ошибочные реквизиты и доступ без сессии. |

| ☐ 11. Smoke и приёмка | frontend · Playwright; orchestrator · итоговый прогон и отчёт | 07–10, включая 03b/07b/08b | На реальном сервере проверены вход, CRUD, ответы и пустое тело 204, перенос с перезагрузкой, две вкладки с Reverb, недоступность чужих данных. Итоговый отчёт содержит тикеты, ссылку на Swagger UI, фактическое покрытие и риски. |

После каждого серверного тикета code-reviewer проверяет diff, Pest и соответствующую часть контракта. При падающем тесте или критическом замечании debugger получает воспроизведение и право исправить затронутый участок. Исправление проходит повторный тест и независимое ревью перед зависимым тикетом.
